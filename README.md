# Ronie.dev — Personal Portfolio

A clean and modern personal portfolio website built with HTML, CSS, and JavaScript.

It showcases featured projects, development tools, an About Me section, and contact links.

#✨ Features

- Responsive and mobile-friendly design
- Modern dark-themed interface
- Animated gradient background orbs
- Smooth scrolling navigation
- Typing text animation
- Scroll reveal animations
- Featured projects section
- Toolkit / skills section
- About Me section
- Contact links for GitHub and email
- Back-to-top button
- Hosted with GitHub Pages

# 🛠️ Technologies Used

- HTML5 — Website structure
- CSS3 — Styling, responsive layout, animations, and effects
- JavaScript — Interactive features and animations
- Font Awesome — Icons
- Google Fonts (Inter) — Typography
- GitHub Pages — Hosting
